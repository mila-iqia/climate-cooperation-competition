# CBAM Regional Configurations

This folder contains region YAML files for the CBAM research project:
*"Consumption Leakage, Strategic Trade Diversion, and CBAM Revenue Recycling"*

Generated by: `scripts/data_preparation/WBAPI_get_data_cbam.ipynb`

---

## Region Design

All setups share the same conceptual structure:
- **Region 1**: EU (the CBAM imposer)
- **Middle regions**: Explicit CBAM-exposed exporters (varies by setup)
- **Last region**: Rest of World — the consumption leakage absorber

Parameters are merged from the calibrated 20-region RICE yamls in `other_yamls/20_regions/`,
using GDP-weighted aggregation. Source RIG groups reference `csv_asset/CountryClass_20.csv`.

## Notes

- `ximport` keys in each yaml are renumbered to match that setup's region count
- Intra-group trade (between merged sub-regions) is removed from the merged `ximport`
- `xexport` is GDP-weighted average across merged sub-regions
- Turkey and Russia both fall in RIG 4 and cannot be separated without a new CountryClass CSV
  (deferred — would require new WB data pull for individual countries)
